# Nova Nexus 星海智能国际站

> 面向开发者与企业的 AI 中台：**多模型统一调用（API 聚合）** ＋ **全流程 AI 短剧制作（网页工作台）**。

本仓库是 Nova Nexus 星海智能国际站的**品牌与开发者展示**项目，用于对外介绍产品能力、开发者接入方式与真实价格对比。

🌐 在线展示（GitHub Pages）：https://li589.github.io/nova-nexus/

## 两件独立的事

| 能力 | 面向谁 | 一句话 |
| :--- | :--- | :--- |
| **多模型统一调用**（API 聚合） | 开发者 / 企业 | 一个 API Key 调遍对话 / 视频 / 图片 / 语音四类模型，OpenAI 兼容，迁移零成本 |
| **全流程 AI 短剧制作**（网页工作台） | 创作者 | 在网页端可视化设计 AI 剧集：剧本 → 分镜 → 出图 → 视频 → 配音 → 成片 |

> 短剧是在网页端「设计」出来的，不是靠一个 API Key 跑出来的；API 统一调用是给开发者把多模型接进自己产品用的。两件事实体分开讲。

## 核心卖点

- **价格透明实测**：真实价格对比可查、可截图、可复核，不做空口「低至 X 折」。
- **开发者视角**：由开发者撰写与维护的接入文档与示例，可信度高于软文。
- **AI 短剧网页台**：同行几乎只做 API 转发，可视化创作台是独占赛道。
- **国内友好**：人民币结算、国内支付直接充值，国产主流模型全覆盖。
