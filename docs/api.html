开发者 API 接入指南

Nova Nexus 提供 OpenAI 兼容的统一 API：一个 Key，调用对话 / 视频 / 图片 / 语音四类模型，统一鉴权、统一计费（人民币 ¥）、迁移零成本。

本页只讲接入方式，不谈价格。模型目录与计费请以官网实时信息为准。

① 快速开始

对话把 base_url 指向 Nova Nexus 网关，其余与 OpenAI SDK 完全一致：

from openai import OpenAI

client = OpenAI(
    base_url="https://dolphin.token6688.com/v1",   # 见官方接入文档
    api_key="YOUR_NOVA_NEXUS_KEY",
)

resp = client.chat.completions.create(
    model="gpt-4o",
    messages=[{"role":"user","content":"用一句话介绍 Nova Nexus"}],
)
print(resp.choices[0].message.content)

Node同样兼容官方 SDK：

import OpenAI from "openai";

const client = new OpenAI({
  baseURL: "https://dolphin.token6688.com/v1",
  apiKey: "YOUR_NOVA_NEXUS_KEY",
});

const resp = await client.chat.completions.create({
  model: "claude-3-5-sonnet",
  messages: [{ role: "user", content: "Hello" }],
});
console.log(resp.choices[0].message.content);

③ 接入要点

  • 统一鉴权：所有模型共用同一个 API Key，无需为每个模型单独申请。
  • 统一计费：一份账单覆盖四类调用，人民币结算，便于对账与成本控制。
  • 国产全覆盖：DeepSeek / Kimi / 智谱 / 通义 / 豆包 / 可灵 / 即梦 / Seedance 等均可调用。
  • 人民币结算：国内支付直接充值，无需双币信用卡。
  • 迁移零成本：已有 OpenAI 兼容代码，仅改 base_url 与 api_key 即可切换。
